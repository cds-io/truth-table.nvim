feat: extract truth-table into a standalone, tested, documented plugin

Pull the TruthTable feature out of the single-file Neovim config modules into a
proper plugin with a pure/impure split, unit tests, and vim help.

- lua/truth-table/core.lua: pure predicate tokenizer/parser, evaluator,
  validation, and markdown formatting. No vim dependency; display-width
  measurement is injectable (pure UTF-8 default, vim.fn.strdisplaywidth in the
  plugin). Adds pure core.expand and core.toggle_cells.
- lua/truth-table/init.lua: vim-coupled layer (cursor table scanning, the
  :TruthTable* commands routed through a shared with_table helper, keymaps) and
  the public setup().
- plugin/truth-table.lua: auto-sourced entry point with a load guard.
- spec/core_spec.lua: 37-case busted spec over the core.
- doc/truth-table.txt: vim help with tags.
- Makefile, selene.toml, README.md, CHANGES.TXT scaffolding.

Behavior is preserved from the original config.
