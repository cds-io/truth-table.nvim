truth-table.nvim changes
========================

Unreleased
----------
- :TruthTableTutor shows the course in two panes: the lesson on the left, one
  step at a time (aim, instructions, expected result), and on the right a
  scratch buffer holding that step's starting text. Each step keeps its own
  scratch, so undo stops at the starting text and work survives moving on.
- Add :TruthTableTutorNext and :TruthTableTutorPrev (]] and [[ in the tutor's
  panes) to move one step, and :TruthTableTutor {lesson} to jump to a lesson.
  :TruthTableTutor! starts the course over and rereads the lesson files.
- The course is data: one Lua table per lesson in tutor/truth-table/ (title,
  aim, steps with text, template, expect, note, solution), replacing
  tutor/truth-table-tutor.md and spec/tutor_steps.lua. spec/tutor.lua replays
  each step's solution in its scratch buffer and requires the result to equal
  the step's expectation.
- Add truth-table.tutor_page (pure Lua): render a step as the lesson pane's
  text, joining hard-wrapped prose into one line per paragraph or list item so
  the window wraps it to its own width.
- Add :TruthTableTutor: a logic course in ten lessons (tutor/truth-table-tutor.md),
  opened as a scratch copy in a new tab; every exercise runs on the tutorial's
  own lines. Running the command again returns to the copy, and ! starts a fresh
  one. spec/tutor.lua replays the exercises and checks them against the
  tutorial's expected blocks.
- Add :TruthTableXor (<leader>tto): recognise an exclusive or or an equivalence
  spelled out as two terms (¬A ∧ B ∨ A ∧ ¬B to A ⊕ B, A ∧ B ∨ ¬A ∧ ¬B to A ⇔ B,
  and the product-of-sums forms), with the cursor anywhere in either term.
- :TruthTableDeMorgan applies at the nearest match around the cursor, so a nested
  match is reachable by putting the cursor in it. From a table's data rows it
  still means the whole heading.
- Add :TruthTableFactor (<leader>ttf), :TruthTableDistribute (<leader>ttx) and
  :TruthTableCommute[!] (<leader>tts, <leader>ttS): preview a rewrite of the
  operand under the cursor, on an expression line or on a table's heading row.
- Add :TruthTableApply (<leader>tta), which replaces in place, and
  :TruthTableApplyStep (<leader>ttA), which inserts the rewrite below as a `≡`
  derivation step and moves the cursor to it. Both serve every preview, De
  Morgan included; :TruthTableDeMorganApply remains as an alias.
- On a line with `≡` separators a rewrite reads the side under the cursor and
  keeps the others. Running a pending preview's own command dismisses it; a
  different rewrite command replaces it.
- Add markdown.heading_cell: the bytes of a heading cell's content.
- Add truth-table.derivation (pure Lua): split a line into sides at ≡, replace one
  side, and build the next `≡` step line, aligned by display column.
- Add rewrite.distribute: multiply an operand into the group beside it
  (¬C ∧ (A ∨ G) to ¬C ∧ A ∨ ¬C ∧ G, and dually). A soundness spec checks every
  rewrite at every cursor byte for truth-table equivalence.
- Add rewrite.factor: pull a shared operand out of the terms of a sum or product
  (A ∧ ¬C ∨ G ∧ ¬C to ¬C ∧ (A ∨ G), and dually for ∨ inside ∧).
- Add truth-table.rewrite (pure Lua): find the operand under a cursor byte, reading
  a run of ∧, ∨, ⊕ or ⇔ as one flat chain, and commute it with its neighbour.
- Add predicate.parse_located: parse_expression's tree with a byte span on every
  node, for cursor-targeted rewrites. parse_expression's output is unchanged.
- Write the Karnaugh formula line as `target ≡ formula` (it was `target = formula`,
  which the predicate language reads as one biconditional). Add ≡ to
  truth-table.symbols and the `equiv@` abbreviation; ≡ stays outside the
  predicate language.
- Add :TruthTableKarnaugh (<leader>ttk): insert below the table a Karnaugh map
  of the column under the cursor and a minimal sum-of-products formula for it
  in the predicate language. Inputs are the shortest left-to-right run of
  columns that distinguishes every row; missing rows are don't-cares (shown as
  X). Maps are drawn for two to four inputs; the formula is always derived.
- Add truth-table.karnaugh (pure Lua: input detection, Quine-McCluskey prime
  implicants, essential primes then a budgeted exact cover with a greedy
  fallback for large functions, map layout) and markdown.format_cells for
  string-cell tables.
- Normal-mode <leader>ttn builds the table from the current line when it is
  nonblank, matching the visual mapping; a blank line still prefills
  `:TruthTable `.
- Preserve explicit setup options during automatic startup; validate abbreviation
  options before mutation and restore displaced user abbreviations on cleanup.
- Register insert-mode abbreviations for the logic symbols (and@ -> ∧, or@,
  xor@, not@, implies@, iff@, forall@, exists@, true@, false@) by default.
  setup({ abbreviations = { trigger, symbols } }) sets the input suffix and
  the per-word display symbols, or `false` disables the set; each setup()
  call replaces what the previous one registered.
- Add truth-table.symbols, one table of ASCII word plus Unicode character per
  logic symbol, shared by the predicate renderer and the abbreviations.
- Render equivalence as ⇔ in generated headings instead of =; `=` remains an
  accepted input spelling.
- Add toggled De Morgan virtual-text previews and explicit apply commands for
  whole expression lines and table headers; invalidate previews after edits.
- Separate predicate language, semantic table model, Markdown codec, and Result
  composition while preserving the string-cell core API through adapters.
- Fix expansion of F/T tables; preserve encoding through semantic operations.
- Add explicit backtick references to stored columns after dropping variables.
- Round-trip escaped pipes/backslashes; preserve grouping in generated headings.
- Validate malformed Markdown and sparse Lua arrays before transformations.
- Compatibility: toggle_cells no longer mutates input; expansion deduplicates
  headings; non-Boolean/mixed tables and empty expressions are now rejected.
- Isolate adjacent tables, ignore fenced/indented code, and preserve supported
  table indentation during edits.
- Report parser errors with source byte positions and complete Unicode characters.
- Support doubled backticks inside references to generated column headings.
- Verify plugin entry-point loading and repeated setup without which-key.
- Escape literal backticks in Markdown headings so rendered labels match stored
  reference names; verify automatic Neovim startup with a real init file.
- Add pure regression specs and headless Neovim command integration checks.

0.1.0 - 2026-06-15
------------------
- Initial extraction from the single-file Neovim config modules
  (lua/plugins/truth-table.lua + lua/truth-table-core.lua). Behavior preserved;
  structure reworked for testability:
  - Split into a pure core (lua/truth-table/core.lua, no vim dependency) and a
    vim-coupled layer (lua/truth-table/init.lua).
  - Removed vim.trim usage from the core (local trim) and made display-width
    measurement injectable: core.display_width defaults to a pure UTF-8
    codepoint count; setup() injects vim.fn.strdisplaywidth.
  - Extracted pure core.expand (predicate parse/validate/eval -> new
    headers+rows) and core.toggle_cells, so the command handlers are thin.
  - Consolidated the command handlers through a shared with_table() helper.
  - setup() registers the same commands, keymaps, and which-key labels as the
    original config.
- Added a busted spec for the core (spec/core_spec.lua), 37 cases.
- Added plugin entry point, vim help (doc/truth-table.txt), Makefile (test/lint),
  selene config, and README.
